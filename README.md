# Wuayna Marka

Sitio web de **Wuayna Marka**, publicado en https://wuaynamarka.lakitasdearica.cl/

Es un clon estático (HTML, CSS y JS, sin PHP) del antiguo sitio WordPress que estaba en el servidor Forge 45.77.151.236, migrado el 2026-10-26. Se publica con GitHub Pages desde la rama `main` (carpeta raíz) y el dominio está definido en `CNAME`.

## Ver en local

```
python3 -m http.server 8000
```

y abrir http://localhost:8000

## Editar y publicar

Edita los archivos `.html` (los recursos están en `assets/`), luego `git commit` y `git push origin main`. GitHub Pages vuelve a publicar en uno o dos minutos.
